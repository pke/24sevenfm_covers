In poster layout, a movie, TV-series, or game backdrop replaces the blurred cover — matched by album title, so it fits soundtrack stations best. No key is required from listeners: this site's resolver searches TMDB and SteamGridDB and prefers curated, usually textless fanart.tv art for screen works. A fanart.tv personal key can unlock fresher artwork. The list above is the priority: drag ⠿ to reorder — the topmost ticked provider that has art wins. That optional personal key is sent to this site's resolver and then to fanart.tv. The browser never calls either provider's metadata API directly. When enabled, current and next queued album titles go through the resolver — see the privacy policy. Artwork-provider credits appear in the footer below.
